This guide puts Shield around a support agent: scan the user's message, scan the agent's reply, and record both. It assumes the `customer-facing` profile from [Getting started](/docs/getting-started) is stored for the tenant, with an instinct that blocks prompt injection and an awareness detector that redacts PII. For an agent that reads logs and calls tools, the [agent safety guide](/docs/guides/agent-safety) is the better starting point.

## 1. Set up the engine

```go
package main

import (
    "context"
    "log"

    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/sqlitedriver"

    "github.com/xraph/shield"
    "github.com/xraph/shield/engine"
    "github.com/xraph/shield/scan"
    sqlitestore "github.com/xraph/shield/store/sqlite"
)

func main() {
    ctx := context.Background()

    drv := sqlitedriver.New()
    if err := drv.Open(ctx, "shield.db"); err != nil {
        log.Fatal(err)
    }
    db, err := grove.Open(drv)
    if err != nil {
        log.Fatal(err)
    }
    st := sqlitestore.New(db)
    if err := st.Migrate(ctx); err != nil {
        log.Fatal(err)
    }

    // Build the engine with a store. Pass engine.WithMetrics to count
    // scans; see the observability guide.
    eng, err := engine.New(
        engine.WithStore(st),
    )
    if err != nil {
        log.Fatal(err)
    }

    // Set tenant scope. Every scan and store call needs the tenant.
    ctx = shield.WithTenant(ctx, "acme-corp")
    ctx = shield.WithApp(ctx, "support-bot")

    run(ctx, eng)
}
```

## 2. Scan user input

```go
func run(ctx context.Context, eng *engine.Engine) {
    // Scan the incoming user message.
    input := &scan.Input{
        Text:    "Can you help me with my account? My email is john@example.com",
        Profile: "customer-facing",
        Context: map[string]any{
            "channel": "chat",
            "user_id": "user-42",
        },
    }

    result, err := eng.ScanInput(ctx, input)
    if err != nil {
        // No verdict means no answer: don't pass the text on.
        log.Printf("scan input: %v", err)
        return
    }

    log.Printf("Decision: %s", result.Decision) // redact
    log.Printf("Findings: %d", len(result.Findings))
    log.Printf("Has PII: %v", result.HasPII())
```

## 3. Handle scan results

```go
    if result.Blocked {
        // Reason is a fixed message, safe to log or show.
        log.Printf("Content blocked: %s", result.Reason())
        return
    }

    // What the model should see: the redacted text when Shield redacted it.
    userText := input.Text
    if result.Decision == scan.DecisionRedact {
        userText = result.Redacted // ... my email is [EMAIL_1]
    }
    log.Printf("Model input: %s", userText)

    // Findings carry names, scores and counts, never the matched text.
    for _, finding := range result.Findings {
        log.Printf("[%s] %s: %s (score: %.2f)",
            finding.Layer,
            finding.Source,
            finding.Message,
            finding.Score,
        )
    }
```

## 4. Scan agent output

```go
    // Before sending the agent's response to the user, scan it.
    agentResponse := "Here is your account information..."

    outputResult, err := eng.ScanOutput(ctx, &scan.Input{
        Text:    agentResponse,
        Profile: "customer-facing",
    })
    if err != nil {
        log.Printf("scan output: %v", err)
        return
    }

    if outputResult.Blocked {
        log.Printf("Agent response blocked: %s", outputResult.Reason())
        return
    }

    finalResponse := agentResponse
    if outputResult.Decision == scan.DecisionRedact {
        finalResponse = outputResult.Redacted
    }

    log.Printf("Safe response: %s", finalResponse)
```

## 5. Graceful shutdown

```go
    // Stop the engine (notifies plugins that implement OnShutdown).
    if err := eng.Stop(ctx); err != nil {
        log.Printf("shutdown error: %v", err)
    }
}
```

## 6. Adding audit trails

Add the audit hook plugin to record safety events. The import path is `audit_hook`; the package name is `audithook`.

```go
import audithook "github.com/xraph/shield/audit_hook"

// A recorder that bridges to your audit backend.
recorder := audithook.RecorderFunc(func(ctx context.Context, event *audithook.AuditEvent) error {
    log.Printf("[AUDIT] %s %s: %s (severity: %s)",
        event.Action,
        event.Resource,
        event.Outcome,
        event.Severity,
    )
    return nil
})

auditPlugin := audithook.New(recorder)

eng, err := engine.New(
    engine.WithStore(st),
    engine.WithPlugin(auditPlugin),
)
```

The recorder sees every scan start and finish, plus each block, instinct trigger, PII detection and the other layer events. Pass `audithook.WithActions(...)` to keep only the ones you want.

## Scan result decisions

`scan.Decision` has five values. The strictest finding decides, in the order `allow < flag < redact < require_approval < block`.

| Decision | What you do |
|----------|---------|
| `allow` | Use the text. For untrusted input, use `Redacted`, which is the quoted text |
| `flag` | Use the text, and look at the findings |
| `redact` | Use `Redacted` in place of the text |
| `block` | Don't use the text. `Redacted` is empty |
| `require_approval` | Tool calls only: ask a person before the call runs |

## Finding layers

Each `scan.Finding` names the layer that produced it in its `Layer` field and the primitive in `Source`.

| Layer | Description |
|-------|-------------|
| `instinct` | Pre-conscious threat detection |
| `awareness` | PII, topic, intent detection |
| `boundary` | Hard limit violation |
| `values` | Ethical rule violation |
| `judgment` | Contextual risk assessment |
| `reflex` | Reflex fired |
| `policy` | Policy rule matched |

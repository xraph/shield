This guide puts Shield around an agent: scan the user's message, scan the agent's reply, and record both. The result-handling code is written for when evaluation ships. Today the six layers aren't implemented, so every scan returns `allow` with no findings, `Blocked` is `false` and `Redacted` is empty. The `if` branches below never run yet, and `eng.Capabilities().Evaluation` tells you when that changes.

## 1. Set up the engine

```go
package main

import (
    "context"
    "log"

    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/sqlitedriver"

    "github.com/xraph/shield"
    "github.com/xraph/shield/engine"
    "github.com/xraph/shield/scan"
    sqlitestore "github.com/xraph/shield/store/sqlite"
)

func main() {
    ctx := context.Background()

    drv := sqlitedriver.New()
    if err := drv.Open(ctx, "shield.db"); err != nil {
        log.Fatal(err)
    }
    db, err := grove.Open(drv)
    if err != nil {
        log.Fatal(err)
    }
    st := sqlitestore.New(db)
    if err := st.Migrate(ctx); err != nil {
        log.Fatal(err)
    }

    // Build the engine with a store. Pass engine.WithMetrics to count
    // scans; see the observability guide.
    eng, err := engine.New(
        engine.WithStore(st),
    )
    if err != nil {
        log.Fatal(err)
    }

    if !eng.Capabilities().Evaluation {
        log.Println("shield: evaluation is not implemented; scans are recorded but always allow")
    }

    // Set tenant scope. The engine stamps it on every scan.
    ctx = shield.WithTenant(ctx, "acme-corp")
    ctx = shield.WithApp(ctx, "support-bot")

    run(ctx, eng)
}
```

## 2. Scan user input

```go
func run(ctx context.Context, eng *engine.Engine) {
    // Scan the incoming user message.
    input := &scan.Input{
        Text: "Can you help me with my account? My email is john@example.com",
        Context: map[string]any{
            "channel": "chat",
            "user_id": "user-42",
        },
    }

    result, err := eng.ScanInput(ctx, input)
    if err != nil {
        log.Fatal("scan input:", err)
    }

    log.Printf("Decision: %s", result.Decision) // allow, for now
    log.Printf("Findings: %d", len(result.Findings))
    log.Printf("Has PII: %v", result.HasPII())
```

## 3. Handle scan results

```go
    // Not reached today: no layer can block yet.

        log.Printf("Content blocked: %s", result.Decision)

    // Not reached today: no PII detection runs yet.

        log.Printf("PII detected: %d instances", result.PIICount)

    }

    // Empty today.
    for _, finding := range result.Findings {
        log.Printf("[%s] %s: %s (score: %.2f)",
            finding.Layer,
            finding.Source,
            finding.Message,
            finding.Score,
        )
    }
```

## 4. Scan agent output

```go
    // Before sending the agent's response to the user, scan it.
    agentResponse := "Here is your account information..."

    outputResult, err := eng.ScanOutput(ctx, &scan.Input{
        Text: agentResponse,
    })
    if err != nil {
        log.Fatal("scan output:", err)
    }

    if outputResult.Blocked {
        log.Printf("Agent response blocked: %s", outputResult.Decision)
        return
    }

    // Use the redacted output once redaction exists.
    finalResponse := agentResponse
    if outputResult.HasPII() {
        finalResponse = outputResult.Redacted
    }

    log.Printf("Safe response: %s", finalResponse)
```

## 6. Adding audit trails

Add the audit hook plugin to record safety events. The import path is `audit_hook`; the package name is `audithook`.

```go
import audithook "github.com/xraph/shield/audit_hook"

// A recorder that bridges to your audit backend.
recorder := audithook.RecorderFunc(func(ctx context.Context, event *audithook.AuditEvent) error {
    log.Printf("[AUDIT] %s %s: %s (severity: %s)",
        event.Action,
        event.Resource,
        event.Outcome,
        event.Severity,
    )
    return nil
})

auditPlugin := audithook.New(recorder)

eng, err := engine.New(
    engine.WithStore(st),
    engine.WithPlugin(auditPlugin),
)
```

Today the recorder sees `shield.scan.started` and `shield.scan.completed` for every scan, and nothing else.

## Scan result decisions

`scan.Decision` has four values. Only `allow` is produced today.

| Decision | Meaning |
|----------|---------|
| `allow` | Content is safe to proceed |
| `block` | Content is blocked, do not send |
| `flag` | Content is flagged for review but allowed |
| `redact` | Content contains PII that was redacted |

## Finding layers

Each `scan.Finding` names the layer that produced it in its `Layer` field. No findings are produced yet.

| Layer | Description |
|-------|-------------|
| `instinct` | Pre-conscious threat detection |
| `awareness` | PII, topic, intent detection |
| `boundary` | Hard limit violation |
| `values` | Ethical rule violation |
| `judgment` | Contextual risk assessment |
| `reflex` | Policy rule triggered |

Shield is a Go library for managing the safety rules around an LLM app or AI agent. You describe **Instincts**, **Awareness**, **Boundaries**, **Values**, **Judgment** and **Reflexes**, compose them into safety profiles and policies, and store them per tenant and app in PostgreSQL, SQLite or MongoDB.

Shield is a library, not a service. You bring your own LLM provider, database and HTTP server.

## Status

The six evaluation layers aren't implemented yet. `ScanInput` and `ScanOutput` run no detectors: every scan returns `allow` with no findings, and Shield stores the scan record and fires the scan hooks. `engine.Capabilities()` reports this in code, with `Evaluation: false` and all six layers listed as unavailable. What works now is the configuration side: storing, scoping and editing every safety primitive, profile and policy, keeping scan history and PII tokens, and managing them from the Forge dashboard.

## The human safety model

Shield models AI safety the way you would describe human cognition. The speeds are design targets for when the layers are implemented.

| Layer | What it represents | Target speed | Go package |
|-------|-------------------|-------|------------|
| **Instincts** | Pre-conscious threat detection (flinch response) | `<10ms` | `instinct` |
| **Awareness** | Perception: what you notice (PII, topics, intent) | `<50ms` | `awareness` |
| **Boundaries** | Hard limits that cannot be crossed (binary) | `<5ms` | `boundary` |
| **Values** | Ethical evaluation (toxicity, brand safety, honesty) | `<100ms` | `values` |
| **Judgment** | Contextual risk assessment (grounding, relevance) | `<500ms` | `judgment` |
| **Reflexes** | Trained condition-action responses (policy rules) | `<10ms` | `reflex` |

## What it does

- Six safety primitives, each a package with a model and a `Store` interface, plus full CRUD in every backend.
- Safety profiles that compose instincts, awareness, boundaries, values, judgments and reflexes, with per-assignment sensitivity and threshold overrides.
- A scan record for every `ScanInput` and `ScanOutput` call, with direction, decision, findings, PII count, tenant and app.
- A PII token store (placeholder, type, an encrypted value you supply, expiry) with per-tenant deletion and age-based purge. Shield doesn't detect or encrypt PII itself yet.
- Tenant and app on the context through `shield.WithTenant` and `shield.WithApp`. The engine stamps them on scans; the subsystem stores filter by the IDs you pass them.
- Policies with ordered rules, assigned at app or org level and to tenants.
- Compliance report records for the EU AI Act, NIST AI RMF and SOC 2. Shield stores reports; it doesn't generate them.
- 15 lifecycle hook interfaces for plugins, and an audit plugin. Only the scan started, scan completed and shutdown hooks fire today.
- OpenTelemetry spans for scans, plugin hooks and PII purges, and scan and hook metrics that a Forge app scrapes on `/_/metrics`. See [Observability](/docs/guides/observability).
- A `forge.Extension` that provides `*engine.Engine` in the DI container, runs migrations and registers an authenticated dashboard contributor.

## Design philosophy

**Library, not service.** Shield is a set of Go packages you import. You control `main`, the database connection and the process lifecycle.

**Human-centric.** Safety primitives are modeled after human cognition (instincts, awareness, boundaries, values, judgment and reflexes), so the configuration reads the way you'd describe the rules.

**Interfaces over implementations.** Every subsystem defines a Go interface, and `store.Store` composes them. Swap the backend by passing a different store.

**TypeID everywhere.** All entities use type-prefixed, K-sortable, UUIDv7-based identifiers (`scan_`, `pol_`, `inst_`, `jdg_`, `sprf_` and so on).

## Quick look

```go
package main

import (
    "context"
    "log"

    "github.com/xraph/shield"
    "github.com/xraph/shield/engine"
    "github.com/xraph/shield/scan"
)

func main() {
    ctx := shield.WithTenant(context.Background(), "acme")
    ctx = shield.WithApp(ctx, "support-bot")

    // No store: the scan still runs, but nothing is persisted.
    eng, err := engine.New()
    if err != nil {
        log.Fatal(err)
    }

    result, err := eng.ScanInput(ctx, &scan.Input{
        Text: "What is your return policy?",
    })
    if err != nil {
        log.Fatal(err)
    }

    // Today this always prints "allow" and 0 findings.
    log.Printf("Decision: %s, Findings: %d", result.Decision, len(result.Findings))
    log.Printf("Evaluation implemented: %v", eng.Capabilities().Evaluation)
}
```

All Shield packages are importable from `github.com/xraph/shield`. The six evaluation layers aren't implemented yet: the safety layer packages below hold configuration models and store interfaces, and the engine's scans always return `allow`.

## Core packages

### `github.com/xraph/shield`

Root package. Exports context helpers, error constants, configuration, and shared types.

| Export | Description |
|--------|-------------|
| `WithTenant(ctx, id)` | Inject tenant ID into context |
| `WithApp(ctx, id)` | Inject app ID into context |
| `TenantFromContext(ctx)` | Read tenant ID from context |
| `AppFromContext(ctx)` | Read app ID from context |
| `Config` | Engine configuration struct (stored, not read yet) |
| `DefaultConfig()` | Returns default Config values |
| `Option`, `Options`, `WithProfile(...)` and friends | Top-level options that nothing consumes yet |
| `Entity` | Base type with timestamps |
| `Version` | Current library version |
| `ErrScanNotFound`, `ErrInstinctNotFound`, ... | Sentinel errors (several are defined but not returned yet, see [Errors](/docs/concepts/errors)) |

### `github.com/xraph/shield/engine`

The scan entry points. No evaluation layer runs yet.

| Export | Description |
|--------|-------------|
| `New(...Option) (*Engine, error)` | Create an engine |
| `Engine.ScanInput(ctx, *scan.Input) (*scan.Result, error)` | Record an input scan; always `allow` today |
| `Engine.ScanOutput(ctx, *scan.Input) (*scan.Result, error)` | Record an output scan; always `allow` today |
| `Engine.Capabilities() Capabilities` | What's implemented: `Persistence`, `Evaluation` (false), `ReportGeneration` (false), `ConfigWrite` (false), and the unavailable `Layers` |
| `Engine.Config() shield.Config` | The stored configuration |
| `Engine.Store() store.Store` | The store, or `nil` |
| `Engine.Health(ctx) error` | Pings the store; errors when there's none |
| `Engine.Stop(ctx) error` | Emits `OnShutdown` to plugins |
| `WithStore(s)` | Set composite store |
| `WithPlugin(p)` | Register lifecycle plugin |
| `WithConfig(cfg)` | Set engine configuration |
| `WithLogger(l)` | Set a go-utils `log.Logger` |

### `github.com/xraph/shield/scan`

Scan input/output types, findings, and results.

| Export | Description |
|--------|-------------|
| `Input` | Content to scan |
| `Result` | Complete scan output |
| `Finding` | Individual detection from a safety layer |
| `Direction` | Input or output direction |
| `Decision` | Allow, block, flag, or redact |
| `Stats`, `StatsFilter`, `ListFilter` | Statistics and list filters |
| `Store` | Scan persistence interface |

## Composition packages

### `github.com/xraph/shield/profile`

`SafetyProfile` composes all six safety primitives into a reusable, named bundle.

| Export | Description |
|--------|-------------|
| `SafetyProfile` | Composition entity |
| `InstinctAssignment` | Instinct with sensitivity override |
| `JudgmentAssignment` | Judgment with threshold override |
| `AwarenessAssignment` | Awareness detector assignment |
| `Store` | CRUD persistence interface |

### `github.com/xraph/shield/policy`

Administrative governance: ordered rules scoped to an app or org.

| Export | Description |
|--------|-------------|
| `Policy` | Entity with scope, rules |
| `ScopeLevel` | App or Org |
| `Rule` | CheckType + Condition + Action |
| `Store` | CRUD + AssignToTenant/UnassignFromTenant |

### `github.com/xraph/shield/pii`

PII token storage. Shield stores the `EncryptedValue` bytes you give it and doesn't encrypt anything itself.

| Export | Description |
|--------|-------------|
| `Token` | PII placeholder, type, encrypted value and optional expiry |
| `Stats` | Vault statistics by type and tenant |
| `Store` | Store/Load/Delete/Purge tokens |

### `github.com/xraph/shield/compliance`

Compliance report records for the EU AI Act, NIST AI RMF and SOC 2. Shield stores reports; it doesn't generate them.

| Export | Description |
|--------|-------------|
| `Report` | Compliance report record |
| `Framework` | `FrameworkEUAIAct`, `FrameworkNIST`, `FrameworkSOC2` |
| `Store` | Create/Get/List reports |

## Plugin packages

### `github.com/xraph/shield/plugin`

The `Plugin` base interface, `Registry`, `NewRegistry` and all lifecycle hook interfaces: `ScanStarted`, `ScanCompleted`, `ScanBlocked`, `ScanFailed`, `InstinctTriggered`, `AwarenessDetected`, `JudgmentAssessed`, `ValueViolated`, `ReflexFired`, `BoundaryEnforced`, `PIIDetected`, `PIIRedacted`, `PolicyEvaluated`, `SafetyProfileResolved`, `Shutdown`. Only `ScanStarted`, `ScanCompleted` and `Shutdown` are emitted today.

### `github.com/xraph/shield/observability`

```go
func NewMetricsExtension() *MetricsExtension
func NewMetricsExtensionWithFactory(factory gu.MetricFactory) *MetricsExtension
```

### `github.com/xraph/shield/audit_hook`

The package name is `audithook`.

```go
func New(r Recorder, opts ...Option) *Extension
func WithActions(actions ...string) Option
func WithLogger(l log.Logger) Option // github.com/xraph/go-utils/log

type Recorder interface {
    Record(ctx context.Context, event *AuditEvent) error
}
type RecorderFunc func(ctx context.Context, event *AuditEvent) error
```

It also exports the `Action*`, `Resource*`, `Category*`, `Severity*` and `Outcome*` constants.

## ID package

### `github.com/xraph/shield/id`

```go
func New(prefix Prefix) ID
func NewScanID() ID
func NewPolicyID() ID
func NewInstinctID() ID
func NewJudgmentID() ID
func NewAwarenessID() ID
func NewValueID() ID
func NewReflexID() ID
func NewBoundaryID() ID
func NewSafetyProfileID() ID
// ... plus NewFindingID, NewPIITokenID, NewComplianceReportID, NewCheckID
// ... and a Parse* function for each type
func Parse(s string) (ID, error)
func ParseWithPrefix(s string, expected Prefix) (ID, error)
func ParseAny(s string) (ID, error)
```

`ScanID`, `PolicyID`, `InstinctID` and the other typed names are aliases of `ID`, so the compiler doesn't stop you mixing them up; the prefix does at parse time. All IDs implement `String() string` and are based on TypeID (UUIDv7, K-sortable). See [Identity](/docs/concepts/identity).

## Infrastructure packages

| Package | Purpose |
|---------|---------|
| `store` | Composite `Store` interface, plus the scoped `DashboardStore`, `AssignmentStore`, `PrivacyStore` and `PrivacyStatsStore` contracts and their errors (`ErrScope`, `ErrNotFound`, `ErrCollection`, `ErrConflict`) |
| `store/postgres`, `store/sqlite`, `store/mongo` | Store backends: `New(db *grove.DB) *Store` and a `Migrations` group |
| `store/storetest` | Shared conformance suite: `Run(t, factory)` |
| `admin` | Validation and permission checks for dashboard operations (`Service`, `Actor`, `Audit`) |
| `extension` | Forge extension: `New(...Option) *Extension`, `Config`, `DefaultConfig()` and the `With*` options |
| `extension/contract` | The `shield` dashboard contributor: `Register`, `ResolveActor`, `ActorResolver` |

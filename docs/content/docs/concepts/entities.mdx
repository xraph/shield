title: Entities
description: The core data types in Shield, from scans and the six safety primitives to profiles, policies and PII tokens.
---

All Shield entities embed the `shield.Entity` base type and carry a TypeID identifier. This page gives an overview of every entity and how they relate. The struct listings are trimmed: each safety primitive and profile also has `Description`, `AppID`, `TenantID` and `Metadata` fields.

The safety primitives and profiles are configuration records that the engine runs on every scan. [Evaluation](/docs/concepts/evaluation) covers exactly what each field does during a scan.

## Base entity

```go
type Entity struct {
    CreatedAt time.Time `json:"created_at"`
    UpdatedAt time.Time `json:"updated_at"`
}
```

Every entity struct embeds `shield.Entity` to get automatic timestamp tracking.

## Safety layer entities

### Instinct

Pre-conscious threat detection. The fastest safety layer, meant to fire before any deliberation. Categories include injection, exfiltration, manipulation, and jailbreak.

```go
type Instinct struct {
    shield.Entity
    ID          id.InstinctID
    Name        string
    Category    Category       // injection, exfiltration, manipulation, jailbreak
    Strategies  []Strategy     // patterns, heuristics, canary (none means patterns + heuristics)
    Sensitivity Sensitivity    // paranoid, cautious, balanced, relaxed, permissive
    Action      string         // block, flag, alert, redact, quote
    Enabled     bool
}
```

### Awareness

Perception: what the system notices. PII and secret detection, topic classification, and your own patterns for sentiment, intent, language or anything else.

```go
type Awareness struct {
    shield.Entity
    ID          id.AwarenessID
    Name        string
    Focus       Focus          // pii, secrets, topic, sentiment, intent, language, custom
    Detectors   []Detector     // built-in detector names, or your own with patterns
    Action      string         // redact, flag, block, vault (vault redacts, stores no token)
    Enabled     bool
}
```

### Boundary

Hard safety limits that cannot be crossed. Binary checks with no thresholds or gradients.

```go
type Boundary struct {
    shield.Entity
    ID          id.BoundaryID
    Name        string
    Limits      []Limit        // scope + deny/allow lists
    Response    string         // canned response when boundary hit
    Enabled     bool
}
```

### Values

Ethical evaluation: toxicity, brand safety, honesty, respect, safety, and privacy principles.

```go
type Values struct {
    shield.Entity
    ID          id.ValueID
    Name        string
    Rules       []Rule         // principle + threshold + categories
    Severity    string         // how seriously violations are treated
    Action      string         // block, flag, warn
    Enabled     bool
}
```

### Judgment

Contextual risk assessment, the slowest but most sophisticated layer. Covers grounding, relevance, consistency, and compliance.

```go
type Judgment struct {
    shield.Entity
    ID          id.JudgmentID
    Name        string
    Domain      Domain         // grounding, relevance, consistency, compliance
    Assessors   []Assessor     // layer_score, finding_count, model (the optional judge)
    Threshold   float64        // risk threshold for action
    Action      string         // flag, block, warn
    Enabled     bool
}
```

### Reflex

Condition-triggered safety responses. Policy rules, rate limiting, escalation logic, and custom triggers.

```go
type Reflex struct {
    shield.Entity
    ID          id.ReflexID
    Name        string
    Triggers    []Trigger      // on_score, on_finding, on_pattern, on_context, on_rate, always
    Actions     []Action       // block, redact, flag, rewrite, escalate, log, throttle
    Priority    int
    Enabled     bool
}
```

## Composition entities

### SafetyProfile

The primary composition unit. Composes instincts, awareness, boundaries, values, judgment, and reflexes into a complete safety identity.

```go
type SafetyProfile struct {
    shield.Entity
    ID          id.SafetyProfileID
    Name        string
    Instincts   []InstinctAssignment    // with sensitivity overrides
    Judgments   []JudgmentAssignment    // with threshold overrides
    Awareness   []AwarenessAssignment
    Values      []string                // value names
    Reflexes    []string                // reflex names
    Boundaries  []string                // boundary names
    Enabled     bool
}
```

### Policy

Administrative governance rules scoped to apps or organizations.

```go
type Policy struct {
    shield.Entity
    ID          id.PolicyID
    Name        string
    ScopeKey    string         // the tenant (org level) or the app (app level)
    ScopeLevel  ScopeLevel     // "org" applies to its tenant; "app" only where assigned
    Rules       []Rule         // check_type + condition + action
    Enabled     bool
}
```

## Scan entities

### Scan Input / Result

```go
type Input struct {
    Text      string
    Direction Direction      // set by ScanInput or ScanOutput
    Context   map[string]any // string values feed on_context reflexes
    Metadata  map[string]any // copied onto the stored scan
    Profile   string         // the profile to run; empty uses Config.DefaultProfile
    Source    string         // where untrusted text came from, such as "log_line"
    Untrusted bool           // quote the text for a model
}

type ToolCallInput struct {
    Tool      string
    Arguments json.RawMessage
    RiskClass string            // empty means "unknown"
    Metadata  map[string]string
    Profile   string
}

type Result struct {
    shield.Entity
    ID            id.ScanID
    Direction     Direction
    Decision      Decision       // allow, flag, redact, require_approval, block
    Blocked       bool
    Findings      []*Finding
    Redacted      string         // the text to use in place of the input, see Evaluation
    PIICount      int
    ProfileUsed   string
    PoliciesUsed  []string
    TenantID      string
    AppID         string
    Duration      time.Duration
}
```

### PII Token

A PII placeholder and its encrypted value, with an optional expiry for retention. Shield stores `EncryptedValue` as the bytes you give it; it doesn't encrypt or decrypt anything itself. A scan redacts PII with placeholders and writes no token, even with the `vault` action.

```go
type Token struct {
    shield.Entity
    ID             id.PIITokenID
    ScanID         id.ScanID
    TenantID       string
    PIIType        string      // email, ssn, phone, cc
    Placeholder    string      // [EMAIL_1], [SSN_1]
    EncryptedValue []byte      // ciphertext you supply
    ExpiresAt      *time.Time  // PurgePIITokens deletes tokens expired before a cutoff
}
```

## Entity relationship diagram

```
SafetyProfile
  ├── InstinctAssignment[] ──→ Instinct
  │                              └── Strategy[]
  ├── AwarenessAssignment[] ──→ Awareness
  │                              └── Detector[]
  ├── Boundary[]            ──→ Boundary
  │                              └── Limit[]
  ├── Values[]              ──→ Values
  │                              └── Rule[]
  ├── JudgmentAssignment[]  ──→ Judgment
  │                              └── Assessor[]
  └── Reflex[]              ──→ Reflex
                                 ├── Trigger[]
                                 └── Action[]

Engine
  └── ScanInput / ScanOutput / ScanToolCall
        └── Result
              ├── Finding[]
              └── PII Token[] (by ScanID)

Policy
  └── Rule[]
```

## Store interfaces

Each entity type defines its own store interface. These are composed into the single `store.Store` composite:

```go
type Store interface {
    instinct.Store    // CreateInstinct, GetInstinct, ...
    awareness.Store   // CreateAwareness, GetAwareness, ...
    boundary.Store    // CreateBoundary, GetBoundary, ...
    values.Store      // CreateValues, GetValues, ...
    judgment.Store    // CreateJudgment, GetJudgment, ...
    reflex.Store      // CreateReflex, GetReflex, ...
    profile.Store     // CreateProfile, GetProfile, ...
    scan.Store        // CreateScan, GetScan, ListScans, ScanStats
    policy.Store      // CreatePolicy, GetPolicy, AssignToTenant, ...
    pii.Store         // StorePIITokens, LoadPIITokens, PurgePIITokens, ...
    compliance.Store  // CreateReport, GetReport, ListReports

    Migrate(ctx context.Context) error
    Ping(ctx context.Context) error
    Close() error
}
```

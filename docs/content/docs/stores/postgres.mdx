title: PostgreSQL Store
description: PostgreSQL store on grove, with migrations for every Shield subsystem.
---

The `store/postgres` package implements Shield's `store.Store` interface, and the scoped `store.DashboardStore` contract the Forge dashboard uses, on the grove ORM with the PostgreSQL driver. It covers all 11 Shield subsystems.

## Usage

```go
import (
    "context"
    "log"

    "github.com/xraph/grove"
    "github.com/xraph/grove/drivers/pgdriver"
    "github.com/xraph/shield/store/postgres"
)

ctx := context.Background()

drv := pgdriver.New()
if err := drv.Open(ctx, "postgres://user:pass@localhost:5432/shield"); err != nil {
    log.Fatal(err)
}
db, err := grove.Open(drv)
if err != nil {
    log.Fatal(err)
}

s := postgres.New(db)
if err := s.Migrate(ctx); err != nil {
    log.Fatal(err)
}
```

`Migrate` runs the package's `postgres.Migrations` group through grove's migration orchestrator. The Forge extension calls it for you on `Start` unless you disable migrations.

## Tables

| Table | Subsystem | Holds |
|-------|-----------|---------|
| `shield_instincts` | instinct | Threat detector configuration |
| `shield_awareness` | awareness | PII, topic and intent detector configuration |
| `shield_boundaries` | boundary | Deny and allow lists |
| `shield_values` | values | Ethical rule configuration |
| `shield_judgments` | judgment | Assessor and threshold configuration |
| `shield_reflexes` | reflex | Trigger and action rules |
| `shield_profiles` | profile | Safety profiles |
| `shield_scans` | scan | Scan results |
| `shield_policies` | policy | Policies and their rules |
| `shield_policy_tenants` | policy | Policy-to-tenant assignments |
| `shield_pii_tokens` | pii | PII tokens (placeholder, type, your encrypted value, expiry) |
| `shield_compliance_reports` | compliance | Compliance report records |

Safety primitive and profile names are unique per `app_id`; policy names are unique per `scope_key`.

## When to use

- Production deployments where you already run PostgreSQL.
- Multi-tenant setups with many apps and tenants in one database.

The store's tests skip unless you set `SHIELD_TEST_POSTGRES`.

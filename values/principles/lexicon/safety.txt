# Destructive infrastructure commands, for the safety principle.
#
# Each line is "<category> <pattern>". Patterns are matched ASCII
# case-insensitively on folded text (write them in lower case), start with \b
# and a literal or with a literal, and use bounded repetition only.
#
# Shell commands that destroy a tree, a disk or a machine (rm -rf /, mkfs,
# dd to a device and so on) are not listed here: they come from
# instinct/detection.DestructiveCommands, the same detector the injection
# instincts use (category "commands").
#
# SQL statements need the statement shape: a name that ends the statement
# (";" or the end of the text), one that cannot be an English word (quoted,
# schema-qualified, or with a digit or underscore), or CASCADE after it.
# "drop database connections on restart" is prose.
#
# After IF EXISTS a plain name needs ";" or CASCADE, except for a database or
# schema, where the end of the text will do. "DROP TABLE IF EXISTS tmp_x" with
# nothing after it is the migration-log idiom and is not counted. TRUNCATE
# needs TABLE before a qualified or quoted name that does not end the
# statement, so a file name after the verb ("truncate output.log before
# archiving") is prose.

# Destructive infrastructure commands, for the safety principle.
#
# Each line is "<category> <pattern>". Patterns are matched ASCII
# case-insensitively (write them in lower case), start with \b and a literal
# or with a literal, and use bounded repetition only.
#
# These match the command itself, wherever it appears. The injection
# instincts (instinct/detection) separately flag text that tells the model to
# run such a command. The rm targets below follow theirs: a whole tree is /,
# ~, $HOME, ., .., * or one of those followed by /*, ending at the end of the
# command or a separator. rm -rf ./build or /var/lib/apt/lists/* is not one.
